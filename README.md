# B-bot-AI-QQ-

一款把 AI 大模型接入 QQ 的安卓机器人。除调用大模型 API 和 QQ 消息收发需要联网外，其余全部在手机本地运行。


一、安装


支持架构：arm64（覆盖几乎所有骁龙、天玑等主流芯片）

最低系统：Android 7.0（minSdk 24）

首次安装请允许"安装未知来源应用"


安装包：B-bot-v1.0.9.apk



二、首次使用流程


安装 Linux 环境（首页 → "安装 Linux 环境"）
会下载 Ubuntu rootfs、QQ、NapCat 并自动配置（约数百 MB，视网络数分钟）
proot 引导程序已内置在 APK 里，无需额外下载

配置大模型（底部导航 → "设置"）
选择服务商、填入 API Key、按需改模型名
设置 Bot 的角色提示词
选择群聊回复策略（仅 @ 回复 / 主动回复）
保存

启动 Bot（首页 → "启动 B-bot"）
状态指示灯会显示 Linux 环境、QQ 连接、Bot 服务三项

扫码登录 QQ（首页 → "扫码登录 QQ"）
会打开内置网页（NapCat WebUI），扫码后 Bot 登录该 QQ 账号


三、支持的大模型服务商

MiMo、DeepSeek、OpenAI、Kimi、Claude、豆包、通义千问、xAI，以及自定义（OpenAI 兼容协议）。


四、回复规则


私聊：始终主动回复

群聊：按你的设置，只在被 @ 时回复，或持续识别并主动回复

图片：开启"识别图片"后，Bot 能看懂你发的图（多模态）

上下文：Bot 记得当前对话的历史（本地保存）


五、重要说明与已知边界


联网范围：只有"调用大模型 API"和"QQ 消息收发"走网络，其余（环境、配置、会话记录、日志）全在设备本地。

首次安装需联网下载 Linux 环境与 QQ，之后运行仍需联网用于 API 与 QQ。

QQ 登录：使用 NapCat，扫码后 Bot 以该 QQ 账号收发消息。

本构建的验证边界：APK 已在构建期完整编译、签名并通过产物校验（24 个核心类、proot 引导组件均在包内）。但 proot 启动 Ubuntu rootfs、QQ 扫码登录、真实收发消息这条链路需要真机运行环境，未能在当前构建容器内端到端跑通——请以真机实际运行为准。

电量与后台：Bot 以后台服务常驻，请在系统设置里把 B-bot 加入电池优化白名单，避免被系统杀后台。


六、隐私


API Key、角色提示词、会话历史仅保存在本机。

不上传任何数据到第三方服务器（大模型 API 除外，你配置的服务商）。
